# IA Customer Support Widget (WIP 🚧)

An AI-powered, embeddable live chat widget built for modern websites. It leverages Retrieval-Augmented Generation (RAG) to answer customer queries using custom business documentation.

##  Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **AI Engine:** OpenAI API / LangChain (Incoming)
- **Database:** Supabase Vector (Incoming)

## Features Roadmap
- [ ] Embeddable Floating Chat Bubble UI
- [ ] Real-time streaming AI responses
- [ ] Vector database integration for contextual FAQ (RAG)
- [ ] Admin dashboard to manage knowledge base
